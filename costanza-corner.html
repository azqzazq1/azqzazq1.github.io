OFF-TOPIC / FIELD NOTE

The Costanza school of debugging.

A small detour for the moments when the obvious explanation is a little too obvious.

There is a particular kind of debugging confidence that feels very George Costanza: a completely reasonable explanation, defended with enormous conviction, based on one suspiciously convenient assumption.

The antidote is less dramatic. Write down the assumption. Find the place where it should become observable. Check whether the evidence actually agrees.

A very small debugging ritual

  1. Name the thing you think must be true.
  2. Trace the state change that would make it true.
  3. Test the smallest case that could prove you wrong.
  4. Get coffee before developing a theory about the entire universe.

Sometimes the bug is an object lifetime. Sometimes it is a missing check. Sometimes the debugger is attached to yesterday’s binary. The notebook has room for all three.
