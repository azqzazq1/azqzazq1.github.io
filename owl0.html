WORKBENCH / IN PROGRESS

OWL0: below the operating system.

An x86-64 hypervisor experiment, and a place to explore virtualization and privilege boundaries.

OWL0 is an ongoing experiment, not a production hypervisor or a published vulnerability finding. It sits alongside my Linux kernel work as another way to study the assumptions that hold a system together.

The questions

  • Where does the guest’s view of the machine end and the hypervisor’s authority begin?
  • How should execution state and memory boundaries be represented and inspected?
  • What can small, isolated experiments reveal about privilege transitions?

These are directions for exploration, not claims about implemented features or measured results. Implementation notes and reproducible results belong here as the experiment develops.
